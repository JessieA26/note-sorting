# AI Homework Checklist

## Goal

Design a small project with its own AGENTS.md or CLAUDE.md so an AI can keep adding pages and content by following the same rules. Put the project on GitHub and make the page viewable online.

## Status

Due 11/16 23:59. The late deadline is 11/17 16:00.

## Next steps

1. Write the project rules file and build the page from it.
2. Upload the project to GitHub and publish it with GitHub Pages.
3. Submit the project introduction, the GitHub repository link, the web page link and the rules file.
4. Add a short explanation of how the rules help an AI add a new page or piece of content.
5. Use the title format: school, student ID, department, name, topic.
